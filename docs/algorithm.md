# 算法、修订与实现对应

本文件记录研究实现的实际数学语义。原式反例与修订实现是两条不同路径，
不能将修订实现的测试成功解释为原交底书的正确性或安全性已获证明。

## 1. 记号和精确取整

环为 `R_M = Z_M[X]/(X^N+1)`，模块维度默认 `l=k=2`，现支持独立配置 `l、k`；私钥为 `(1,-s0,...,-s_(k-1))`。
代码 `level=0` 表示顶层，level 增大表示丢弃末尾主模数塔。

- P：顶层主模数，即 OpenFHE 的主链乘积。
- H：当前 level 的主模数，主链前缀的乘积。
- Q：OpenFHE HYBRID 辅助素数乘积；OpenFHE 通常将该辅助模数称为 P。
- T：修订版公钥模数，对应原文 q'。
- W：修订版新增的独立取整源模数。
- Delta：编码器输出及后续实际运算跟踪的尺度。

`SR(B→C,x) = round(C * center_B(x) / B) mod C`，逐个完整整数系数计算。
模数均为奇数，因而没有半整数平局。对目标模 C，使用非负源代表元并计算
`((x*C + floor(B/2))/B) mod C` 完全等价，代码采用这一写法。
中心提升只改变表示，不乘尺度：`Lift(B→C,x)=center_B(x) mod C`。

NTT 加乘由 OpenFHE `DCRTPoly` 完成。跨基算子先回系数域、CRT 重构，
用 BigInteger 精确运算，再转回目标 RNS/NTT 域。
不能逐塔取整，也不能直接用 `Q^-1 mod H` 代替整体除 Q 后舍入。

## 2. 原式反例

`tests/test_source_counterexamples.py` 使用独立 Python 整数多项式算术，
通过逐素数的系数线性系统求解实现公开恢复。小环用于说明代数问题，
不用于声称某个具体大参数的攻击耗时。

### 重线性化符号

两个密文相位的乘积是 `d0-d1*s+d2*(s tensor s)`。
原评估密钥相位是正的 `Q*(s tensor s)`，因此必须加上转换项。
例如 `s=(1,0), c=c'=(0,1,0)`，解密值为 -1，平方应为 +1；原减号输出 -1。
普通换钥的一次项仍需减号，不能一起改为加号。

### 取整方向与公开恢复

若 C>B，则 `SR(C→B, SR(B→C,x))=x`：扩模最近舍入可逆。
在 l=k=2 且随机公钥矩阵可逆时，原式存在以下问题：

| 原 q' 与 P 的关系 | 公开恢复路径 |
|---|---|
| q'<P | 密文尾部反向取整得到 `A^T r mod q'`；解出 r，从 c0 消去掩码恢复消息 |
| q'=P | 公钥直接给出 `b=A*s`，取整消失 |
| q'>P | 公钥反向取整恢复 A' 和 A's，进而解出 s |

脚本使用 `N=4, P=97*113, q'=17*41` 和原式 `P/t` 嵌入（t=113）验证
不读取秘密的消息恢复；q'>P 使用另一独立素数链。奇异矩阵跳过，记录可逆样例数。
此外，q'<P/2 的原换钥密钥可投影回无噪声关系；脚本检查 200 行。
“选择互素的 q'”不能解决这些结构性问题。

### 编码及维度

原式直接 round 逆嵌入，常数 0.125 编码为零，乘法后的尺度也未定义。
`s^T s` 是标量，不能对应 k² 行；修订明确使用顺序
`(s0*s0, s0*s1, s1*s0, s1*s1)`（k=2 时）；一般 k 按 `i*k+j` 排列。换钥输入秘密有 k 个分量，
评估密钥目标环统一为 R_(PQ)。

## 3. 修订研究构造

**以下是实质性构造修改，不是仅修排版。安全性仍未证明。**

选择独立、互素的 RNS 链，满足 `T>P`、`W>max(T,PQ)`。
代码复制目标链各塔的邻近但不同的 NTT 素数，再加一个 30 位素数，
排除主链、辅助链和其他新增链中已用的素数。实际值写入执行报告。
构造后检查上述不等式；新增模数不声称是 OpenFHE 默认参数。
邻近素数和额外 30 位塔是明确的研究参数选择，不是 MLWR 安全认证。

### 密钥生成：替代原 (2-1)

秘密 s 的 k 个分量独立采用 OpenFHE 均匀三元采样，每个多项式各塔表示同一组系数。

```
A* ← uniform R_W^(l×k)
A = SR(W→T,A*)
b = SR(W→T,A* s)
pk = (b,A), sk = (1,-s)
```

源矩阵不发布。与原式从 P 取整到 q' 不同，这里从 W 压缩到 T。

### 编码、加解密：修订 (3-2)、(3-3)、(4-1)、(4-3)

```
m = round(Delta * sigma^-1(z))
r ← independent uniform ternary polynomials, length l
c0 = SR(T→P,b^T r) + m  mod P
c1 = SR(T→P,A^T r)      mod P
z_out = sigma(center_H(c0-c1^T s) + uniform_smudge) / Delta
```

显式去除原 P/t 消息嵌入及 t/P、mod t 解密路径，不再使用明文模数 t。
编码使用 OpenFHE CKKSPackedEncoding，数据类型显式设 COMPLEX；默认 REAL 会丢弃虚部。
顶层 FLEXIBLEAUTOEXT 使用编码器的实际大尺度；首次运算前可删除 extra tower。
解码做完整 N/2 槽的 FFT，再取请求的前缀，保留全部系数噪声的影响。
短输入补零；稀疏打包在完整嵌入中重复。

默认不加解密噪声，用作诊断。非零参数使用 OpenFHE PRNG 产生每系数独立的
均匀整数噪声。原文未给出查询次数、隐藏噪声幅度和精度预算，不能声称 IND-CPA^D。

### 统一评估密钥：替代 (2-2)、(7-1)

对每个目标多项式 f，每行独立采样：

```
a* ← uniform R_W^(1×k)
ek_a = SR(W→PQ,a*)
ek_b = SR(W→PQ,a* s_target) + Q*f  mod PQ
```

重线性化的 k² 个 f 按 `i*k+j` 顺序对应 `s_i*s_j`；换钥的 k 个 f 是源秘密的 k 个分量；
旋转源秘密为 `kappa_(5^r)(s)`。所有行、所有密钥生成均使用独立源矩阵。

### 运算与重缩放

在当前模数 H 下定义 `K_f(x)=SR(HQ→H, sum_i Lift(H→HQ,x_i)*ek_i)`。
顶层评估密钥只约减为 HQ 的塔，不重缩放。然后：

| 操作 | 公式与尺度 |
|---|---|
| Add | 分量相加；要求相同 key、level、Delta；Delta 不变 |
| PlainMult | 各分量乘编码多项式；Delta 乘明文尺度 |
| Mult | `(d0,d1)+K_(s tensor s)(d2)`；Delta 乘另一密文尺度 |
| Rescale | 各分量一次整体除 `D=H/H'` 并最近舍入；Delta 除实际 D |
| KeySwitch | `(c0,0,...,0)-K_s_source(c1)`；Delta 不变 |
| Rotate | k+1 个分量执行 X→X^(5^r)，再换回原秘密；正 r 左移、负 r 右移 |

主模数链由不同素数相乘，替代原来的精确几何序列 p0*u^h。
没有只修改尺度字段来冒充重缩放。

## 4. 正确性依据与边界

令 `S1=sum_j ||s_j||1`，`K=(1+S1)/2`，三元随机量满足 `R1<=l*N`。
确定性系数界为：

```
||b-A*s||inf <= K
fresh_error <= K*(P/T*R1+1)
||ek_b-ek_a*s-Q*f||inf <= K
switching_added_error <= K*(1+a*N*(H-1)/(2Q))
rescale_phase_discrepancy <= K  (相对于舍入前的精确除法)
```

重线性化 a=k²，普通换钥 a=k。测试用实际秘密的 L1 范数检查公钥、各个评估行、
新鲜相位、乘法相位及重缩放相位，并以独立 Python 大整数核验底层算子。

浮点结果对照宿主复数运算。`1e-6` 是测试电路的经验验收阈值，
不是任意深度、任意输入和任意解密次数的普遍误差定理。
公开幅度上限随加法与乘法传播；尺度下限为 2^40，避免多余重缩放淹没小数。
实现检查尺度、幅度和主模数的基本空间限制，
尚未实现适用于任意电路的完整噪声预算编译器。

无 Bootstrap、安全归约、循环／相关密钥安全证明、常数时间保证或生产审计。
OpenFHE 的 RLWE 安全选择器仅决定共有工程参数，不能验证这里的 MLWR 假设。
